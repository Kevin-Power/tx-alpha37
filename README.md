# TX ALPHA-37

台指期（TX / MTX / TMF）**開盤區間突破（TORB）當沖研究包**。

給人看、也給其他模型看。請先讀 [RESEARCH.md](./RESEARCH.md) 與 [FOR_MODELS.md](./FOR_MODELS.md)，不要只看獲利因子排序。

- 基準策略：**ALPHA-37**（開盤 37 分區間 + VWAP + 波動 + 缺口）——用來殺假故事，不是已確認 edge
- 結構37（再加「昨收在 20 日均之上」）：**採納得太早**，九成增量來自三個大虧月
- 樣本：Yahoo `^TWII` 日線 2024-08-26 → 2026-08-25（485 根）
- 樣本外切：`2025-08-25` 之後
- 契約預設：小台 MTX，本金 50 萬 TWD，單筆風險 1.2%
- 成本：期交稅 2/100,000（買賣各一次）+ 單邊手續費 50 + 每邊滑價 2 點

## 一句話結論

**假 edge 殺得差不多了，策略還沒成形。** 目前唯一種子穩健的結論是負結論：無濾網 TORB 扣完成本後沒有 edge（0/20 條重建路徑 PF>1）。下表的正 PF 全部來自 seed 0，該路徑在 60 條裡排 98–100 百分位；種子中位數下 ALPHA-37 全樣本是虧的。2025 PF 0.988 是否決票；週五拿走七成淨利，2025 的週五 OOS 段 PF 0.84。結構37 九成增量來自三個大虧月，MA 單調性測試失敗。H-11：ATR 擴張放假門檻鎖死 2.0，本樣本從未開火，複製不了 MA20。H-06：≥ 0.8 ATR 放假有條件通過；0.55 順勢不列升級。這不是投資建議。

被推翻：跳過月結算週三（結算當天 18 筆 PF 3.19）、外資水位濾網（37X 更差）、把 0.55 缺口順勢當 A 層升級（H-06）、把結構37 解釋成 ATR 擴張 2.0（H-11，0 日開火）。真正差的是**結算週的週一**（19 筆 PF 0.17）。H-06 有條件通過：≥ 0.8 ATR 整日放假。沒有新預設。

已降級（2026-08-25 種子擾動攻擊輪）：ALPHA-37 濾網「救成勉強賺」→ 未證實；結構37 → 體制依賴（MA 單調性測試失敗）；週五 edge → 未證實（PF 1.63 是 60 條路徑最大值）。資料升級路線見 [DATA_SOURCES.md](./DATA_SOURCES.md)。
