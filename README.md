## 一句話結論

ALPHA-37 **不是印鈔機**。全樣本獲利因子 1.15、樣本外 1.19；2025 年 PF 0.99，2026 年 1.48——OOS 沒崩，但不穩定。H-06 把舊的「缺口濾網」拆開：≥ 0.8 ATR 放假是目前唯一站得住的 A 層 gap 主張（有條件通過）；0.55 順勢幾乎沒加分，不列升級。結構37 數字漂亮，但週四＋週五佔 84% 淨利。1 分 K 是日 OHLC **重建**，ORB-15 當假象。
